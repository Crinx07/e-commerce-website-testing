# E-Commerce Website Testing

A Quality Assurance (QA) portfolio project focused on manual testing, API testing, SQL validation, and CI/CD practice.

## Project Overview

This project demonstrates practical software testing skills using an e-commerce demo website. Testing includes functional test cases, test execution, defect reporting, API testing, database validation practice, and automated test execution through a CI/CD workflow.

## Testing Scope

### Manual Testing
- Login and logout functionality
- Product details and images
- Shopping cart operations
- Product sorting
- Checkout validation and order completion
- Session behavior

### Test Execution
- Documented test cases and actual results
- Compared expected results with actual behavior
- Recorded PASS and FAIL outcomes
- Tested different user accounts and documented observed differences

### Bug Reporting
- Created bug reports with reproduction steps
- Documented expected and actual results
- Linked defects to related test cases
- Recorded observed issues with the SauceDemo `problem_user` account

## Tools and Technologies

- **Manual Testing:** SauceDemo
- **API Testing:** Postman
- **Database Validation Practice:** MySQL and MySQL Workbench
- **Version Control:** Git and GitHub
- **CI/CD:** GitHub Actions
- **API Automation Practice:** Postman CLI
